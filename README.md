Entry for make.fun's "One Line, One Laugh: Roast Your Fridge" bounty: a program that writes exactly one funny line roasting a fridge to `/output/entry.txt`.

> My fridge hums like a jet engine all night and still lets the milk die every Tuesday — ten years on the job, all noise, zero chill.

A specific, recognisable detail (the humming fridge that still can't keep milk alive) with the twist saved for the last few words: a fridge whose one job is chill has, after ten years, zero of it. 131 characters.

## Run it

```sh
node main.ts
```

Node 22+, standard library only, no network, no dependencies. Writes `/output/entry.txt` (UTF-8, one line, 131 characters).
